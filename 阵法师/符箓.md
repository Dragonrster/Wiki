# 符箓

符箓是本服阵法师职业最大的特色，是一种**右键使用、消耗灵气来释放技能**的特殊道具。

## 符箓制作

**制作位置**：皇城 76, 46, 143 处进入画符室。

1. 在 NPC **天师—张道陵** 处购买符纸（依次为二/三/四/五/六阶符纸）
2. 符纸能够装备不高于自身阶级的符箓，越高级的符纸能同时装备越多的符箓
3. 在画符室内右键画符台座位坐下
4. 手持符纸右键画符台上的白色垫纸 → 右键符箓打开选择页面 → 点击想要制作的符箓
5. 半空会出现所需材料，准心指向材料显示所需数目
6. 材料准备足够后，右键画符台上的笔砚完成画符

> 画过的符箓永久学会，即使更换符纸也依然可以装配。

## 符箓装配

- 符纸按 **F 键**打开选择界面，左键符箓来装配/卸下
- 通过**下蹲 + 滚轮**切换已装配符箓

---

## 符箓分类

符箓主要分为五种，**同种符箓共享 CD**：

| 类型 | 说明 |
|------|------|
| **斩将** | 单体伤害 |
| **破阵** | 范围性伤害 |
| **强身** | 给予自身各方面强化回复 |
| **缚灵** | 召唤出作用不同的傀儡 |
| **阻敌** | 弱化限制目标 |

## 符箓制作配方

### 高级符箓

**日曜天地**（破阵）：红符·日曜天地、24 微火种、24 红宝石、12 奇特的灯芯、12 燃火种、1 九阳焱珠

**流光夺命**（斩将）：红符·流光夺命、20 青纹灵骨、20 坚甲蛛壳、10 千年内丹、16 灵铁、12 太极碎星、16 浓缩金、1 太极玄元珠

**九幽寒冰**（阻敌）：红符·九幽寒冰、24 玄湖灵核、20 青纹灵骨、10 灵铁、8 生灵水、12 余泪、1 天音石

### 辅助符箓

**凝气**（强身）：附灵石碎片 ×30、生灵水 ×16、寒山雪莲 ×8、精炼水 ×30、余泪 ×1

**铁傀**（缚灵）：32 附灵石、20 傀尸结晶、8 千年内丹、12 灵铁、1 太极碎星、22 精炼金

**地傀**（缚灵）：28 附灵石、2 皇陵信物、9 怨气碑石、16 玄湖灵核、20 傀尸结晶、24 精炼土

**紊息**（阻敌）：32 附灵石、24 凝怨、12 焦骨、6 怨气碑石、24 精炼水

### 攻击符箓

**潜爆**（破阵）：14 附灵石、7 朱火羽、12 微火种、15 精炼火

**天雷**（斩将）：24 附灵石、1 太极碎星、1 灵玉简、20 玄湖灵核、26 精炼火
