# 符箓

符箓是本服阵法师职业最大的特色，是一种**右键使用、消耗灵气来释放技能**的特殊道具。

## 符箓制作

**制作位置**：皇城 76, 46, 143 处进入画符室。

1. 在 NPC **天师—张道陵** 处购买符纸（依次为二/三/四/五/六阶符纸）
2. 符纸能够装备不高于自身阶级的符箓，越高级的符纸能同时装备越多的符箓
3. 在画符室内右键画符台座位坐下
4. 手持符纸右键画符台上的白色垫纸 → 右键符箓打开选择页面 → 点击想要制作的符箓
5. 半空会出现所需材料，准心指向材料显示所需数目
6. 材料准备足够后，右键画符台上的笔砚完成画符

> 画过的符箓永久学会，即使更换符纸也依然可以装配。

## 符箓装配

- 符纸按 **F 键**打开选择界面，左键符箓来装配/卸下
- 通过**下蹲 + 滚轮**切换已装配符箓

---

## 符箓分类

符箓主要分为五种，**同种符箓共享 CD**：

| 类型 | 说明 |
|------|------|
| **斩将** | 单体伤害 |
| **破阵** | 范围性伤害 |
| **强身** | 给予自身各方面强化回复 |
| **缚灵** | 召唤出作用不同的傀儡 |
| **阻敌** | 弱化限制目标 |

### 注释

- **起爆符**：入门破阵符，低消耗
- **疾行符**：效果较强应用广，推荐优先学习
- **撼地符**：效果中等但少数情况有极佳应用，推荐习得
- **缠须符**：效果极差，绞尽脑汁想不到有啥用，全收集时可习
- **灵箭符**：需要大量箭矢（5组），注意弹药储备
