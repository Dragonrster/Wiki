# 观前须知

为了你的游戏体验能够更加完善，强烈建议您在前期游玩阵法师之前简单观看完此攻略，以便你在以后的游玩途中不会那么迷茫。

**强烈建议您去本服务器群下载由玩家Annijang上传的“盘龙阁懒人包”，并按照压缩包内的安装教程进行下载整合包，懒人包包含了绝大多数的服务器资源和怪物点位，能节省您很多的找资源和找怪所花费的时间。**

# 职业的选择

在选择种族之前，需要了解一下阵法师在盘龙阁服务器中的定位。<br>在原六副本里，阵法师是一个具有全面带飞能力的六边形职业，不仅拥有伤害也有足够的保护队友的能力；在dlc副本里，阵法师不具备带飞能力但战士和弓箭手极度依赖阵法师的浓火和浓土提供的增益，这些增益都与阵法师的强度之戒挂钩，因此不太建议选择除了战神族之外的其他种族。

种族特性在四圣兽试炼与圣山升级，最高六级，在游戏前期能提供极大增益。<br>升级流程：青龙试炼（1 -> 2）、朱雀试炼（2 -> 3）、白虎试炼（3 -> 4）、玄武试炼（4 -> 5）、通关一次圣山（5 -> 6）<br>
战神族：1.5\2.5\3.5\4.5\6\8基础攻击力（最建议选择的种族）<br>
人族：5\10\15\20\25\30基础护甲<br>
神族：5\10\15\20\25\30基础生命<br>
妖族：0.6\0.7\0.8\0.9\1\1.2每秒生命生命回复<br>
仙族：最高15基础生命与最高20基础护甲<br>

由于在盘龙阁服务器中，阵法师在后期的所有元素属性都与阵法强度挂钩，例如：浓缩金元素的伤害、浓缩木元素的回血量、浓缩水元素的虚弱、浓缩火元素的攻击力加成、浓缩土元素的护盾量。**因此，玩炼丹师只推荐选择战神族。**

# 中期（10-40）

当升到10级，将会解锁最基础的炼丹套装，也就是二阶装备，合成此装备需要二阶防具锻核，需要在东方森林击杀树精人获得二阶装备原核之后，在皇城的铁匠铺的装备锻造师处[81 45 151]使用 [1x二阶装备原核和20x铜币] 兑换获得二阶防具锻核。劣质蛛丝可在东方森林击杀蜘蛛类的生物获得。

在升级装备之后，需要去获取升级三阶元素熔炉所需要的材料。前往皇城南部的沙漠（19 49 315）击杀烈焰人体型的生物获取微火种（推荐温泉客栈门口，坐标：-365 68 339），前往东方森林击杀蜘蛛女王（529 38 337）获得蛛腺体，击杀凶神太岁（-186 80 393）获取太岁，前往马贼营地击杀马贼团长（-129 54 745）获得。
在升级三阶武器时，建议同步去收集三阶装备所需要的材料，制作三阶装备需要采集尖火掌和太岁，这些材料获取点位都可以在群文件的懒人包进行查看。

从四阶武器开始，需要去西方白虎洞和雪山山顶收集千年内丹和寒山雪莲，雪莲需要去雪山山顶采集获得，如果有条件也能通过击杀狂躁雪猿获得，其中，狂躁雪猿的坐标是1765 105 1433 （入口：-416 129 177）。除此之外，还需要去北方采集水参和打怪获得玄湖灵核，推荐去李大夫效率点位（-12 52 -614），此点位能够同时获得玄湖灵核、青纹灵骨和坚甲蛛壳三种锻造材料。同时，由于 [李大夫效率点位] 的刷怪数量较多，也比较适合用来刷机，如果你的攻击力不足以刷级，可以制作剑阵符箓之后去白虎洞门口的 [陈大夫草药效率点位] 进行刷级。

# 后期（45-∞）

当步入45级之后，就脱离了中期不需要刷本的阶段，从45级开始，制作五阶装备需要20个太极碎星，因此，我不建议在此阶段依旧通过购买获得，强烈抗议准备若干数量的金钥匙，建议64个起步，因为后面还需要对其他副本进行攻略以获取制作六阶对应装备所需要的装备解封权限。

原版盘灵古域的六阶装备，以下简称原六。

当你的等级达到45级之后，强烈建议首先把五阶武器七煞鼎作为第一个目标进行制作，七煞鼎作为第一个五阶武器，拥有操控并使用浓缩元素的能力。其中，浓缩金具有大范围AOE伤害，当最后在蓬莱的太上老君那升满之后，拥有50格半径的超大攻击范围，远超精炼金升满之后的12格半径攻击范围，因此，浓缩金可用于在墓园深处大量刷取经验的唯一途径，如果你想用剑阵符刷级也不是不行，只是范围和伤害没有浓缩金的大和高而已。

当你拥有60级的七煞鼎之后，当然，这并不刚需，因为你能通过混镇妖塔的反塔来获得比七煞鼎更有用的九黎壶进行替代。同时在60级时，建议也将防具也同步升级到五阶毕业，否则哪怕在后续获得了六阶防具也无法进行升级。

**阵法师的刷级目标阶段：60/90/120/140/150<br>（60级是五阶装备目标、90级是原六毕业目标、120是烧火毕业目标、140是山本毕业目标、150是西本毕业目标）**

## DLC

**DLC副本不欢迎任何摆烂玩家，不欢迎任何没有原六毕业以及10锻以上的玩家！！！**<br>

当你原六毕业之后，就可以考虑尝试攻略本服务器的DLC副本，目前服务器有三个DLC副本，也就是[烧火境]、[峻极殿]、[集灵宫]。其中，烧火境在玩家的日常交流中主要以“烧”、“烧火”的简称为主；峻极殿的简称主要是“山本”、“中岳”为主；集灵宫的简称主要是“西本”、“西岳”为主。

在DLC副本中，请务必按照 **[烧火境] -> [峻极殿] -> [集灵宫]** 的顺序进行攻略，特别是烧火镜。比如说：如果你没有原六毕业就去打烧火镜的话、如果你没有烧火镜毕业就去打峻极殿或者集灵宫的话，你将有很大的可能性会得到到来自其他队友的亲切问候。问候的主要原因只有一个：缺少原六装备或者烧火毕业装备所带来的阵法强度从而导致浓火提供的拐力不足预期。说简单点就是没有原六毕业或者烧火毕业，贸然跨副本打就是队伍的累赘。如果是朋友互相认识的话，那可以无视这句话。

### 烧火镜

>烧火镜坐标：514 53 780 

**以下是针对阵法师玩家的简单攻略，如果你需要了解烧火镜的详细讲解，请移步[烧火镜](/副本相关/烧火境.md)。**

- 烧火镜在组队时，一次最多拥有三名玩家，目前常见的组队配置是201、111，201指的是2个战士+1个阵法师，111指的是1个战士+1个弓箭手+1个阵法师。<br><br>**请勿尝试非正常的职业配置，比如021或者102等，否则你将会在试图攻略烧火镜时很容易遇到被复生炸死等许多影响游戏体验的糟糕情况！！！**<br><br>
- 烧火镜的最终boss为焰火仙，焰火仙在每次被击杀后，等待屏幕中间的进度条满后，焰火仙的全属性（攻击力、生命值等）将会得到提升，也可以站到里面的复生圈（下图的橙圈）按 **[Shift+F]** 跳过读条过程强制复活。<br><br>
- 需要注意的是，焰火仙每次复活都会强制造成**两次全屏伤害**，此伤害无法躲避，但能够通过 **浓土** 和 **土傀** 进行消除和减伤。（土傀可放置在下图的紫圈中）<br><br>
- 焰火仙对阵最大的威胁是**陨石**，当焰火仙发动此技能时，会原地起飞后对全场玩家发动追踪式360度的连续攻击，伤害极高。（建议围绕淡绿圈进行绕圈跑，跑圈路径请务必其他玩家的圈）<br><br>
- 阵法师在烧火镜的主要攻略是：当队伍里的配置是201时，阵需要到场地中间放置一个地傀儡为自己消除焰火仙每次复生所带来的两次伤害，然后按照 **[浓火、浓木、浓土]** 循环放置技能，直到最终全员主动离开或者全员阵亡；当队伍的配置是111时，阵同样需要将土傀放置到场地中间，为弓箭手和自己提供抵消复生伤害的生存能力。<br><br>
- 阵在打烧火镜时，如果你的装备是西岳毕业，则可尝试4散附灵或者2散2聚附灵；如果你的装备属于原六毕业或者山毕业，请务必4聚附灵而不要去带任何数量的散附灵，因为阵法师的最大生命值会等效应用到土傀的生命值上，而土傀的存活时间相当于是阵或者弓在遇到复生导致的爆炸伤害时的第二条命。<br><br>
- 烧火镜和其他副本的死亡机制不一样，因为焰火仙的复生是无限的，所以每次死亡之后不会返回奈何桥，而是传送到奖励房并增加保底进度。<br><br>
- 烧火镜只有在攻略到第9次复生之后，才会出现烧火宝箱，烧火宝箱无法使用银钥匙或者金钥匙打开，需要使用专门的烧火钥匙，烧火钥匙可以在烧火镜门口使用 **[48个火星残砾]** 或者 **[12个焰心碎片]** 在门口的NPC兑换获得，也能使用烧火镜门口打怪掉落的材料进行兑换，请自行选择最适合自己的获取方式。 <br><br>
- 烧火镜的开箱保底是150，从复生9开始，每次复生都会增加1点的保底次数，无上限。阵法师在烧火镜的装备有三个，分别是：[武器]燃火、[饰品]烈日箍、[法宝]赤霄印。在这三个装备出完之前，哪怕中途出了烧火材料业火宝铁也不会清空保底次数。但只要出了这三个装备的其中一个之后，保底进度就会清空。<br><br>

- 第一关：
阵法师在副本刚开局的时候按照 **[浓火、浓木、浓土]** 的流程先给全队上个buff，然后吃灵跃丹跳到任意一个桌子上然后放置一个铁傀儡，放置完之后就可以离开桌子后围绕桌子进行绕圈并补放铁傀儡，最后根据附近玩家的状态给予浓火或者浓木等buff。直到最后队友成功填沙完毕后即可进入第二关。

<br>
 
> **冷知识：阵法师的浓土可以在站到副本最中间位置定住副本内的所有小怪和精英怪，因此可以用来辅助队友进行控制。浓土的控制还能用于控制第五关的小怪和精英怪。**

- 第二关：<br>阵法师需要先给队友放上一次浓水和浓火buff以抵消中毒效果和给予攻击力加成，然后在大树出现之前在己方队友附近放置土傀以抵消大树的亡语，大树的亡语还能通过浓土抵消。


>**冷知识：大树的出现亡语的原因是在死亡时模型的攻击模组不会停止，只需在大树死亡时远离即可避免绝大多数的亡语伤害。**
<br>

- 第三关：<br>开局可以给全队一个浓木以增加队友在挖矿时的容错，开局给予一次就够不要给予第二次，否则如果是在单阵的队伍将会导致全队阵亡。<br>给予一次浓木之后需要在场地上挖掘4-5个矿（单阵建议挖3个矿），其中使用钻石镐必定只有1个矿物，而使用合金镐则是1-2个矿物。<br>挖完矿之后在距离铁傀儡最近的锻造台那放置循环放置2-3个精炼木后等待队友集合，并且将背包里的**炎晶矿**丢给主c玩家。<br>最后在看到主c玩家强化武器后给予浓火，等待铁傀儡阵亡即可前往第四关。<br><br>

- 第五关：<br>第五关会刷新出饥民，饥民能通过采集小麦并喂食的方式缓慢增加屏幕中间的进度，也能通过直接击杀来大幅增加进度，只不过喂食比较安全，击杀则适合竞速。<br>在第五关里，饱食度会极速下降，无法通过常规的食物恢复，只能通过采集小麦后获得的麦梁才能恢复，饱食度降到0时则会受到无视护盾的真实伤害。屏幕中间的进度条满时，则会召唤boss，击杀后进入最终的大帝关。<br>因此，建议阵法师开局跳到桌子上放置铁傀儡吸引仇恨，然后交给战士和弓箭手进行输出，在精英怪出现时，阵法师需要在确保桌子上有铁傀儡的同时给予一次浓土以定住精英怪。<br><br>
- 第六关：<br>大帝的技能机制比较多，但大多数的伤害都不高，所以无需特别在意。<br>在大帝关开始时，阵法师需要按住后退键并在楼梯下方的平地上放置一个铁傀儡以吸引仇恨，因此建议在第五关快结束之前给予全队一个浓木以增加铁傀儡的生命值。<br>放置完铁傀儡之后就可以按照 **[浓火、浓木、浓土]** 的顺序为全队提供增益和恢复，如果有足够的蓝条请务必在浓木之前先使用怨火提灯为大帝挂个易伤，最后请务必确保铁傀儡持续战场，否则弓箭手就会cos减速带然后享福去了。<br>假如队伍的输出不高导致不能一轮秒掉大帝，大帝则会释放一次名为“五土归一”红色字体的大招，唯一的应对方式就是让战士使用诀窍的主动技能“玄龟护法阵”来硬吃大招，如果没有玄龟则在大招结束后全体返回奈何桥，正常情况下在有玄龟的情况下吃了大招之后全体玩家会剩50%的血，此时请务必原地放个精炼木或者浓木来为全队进行回血。<br>大帝的大招每一局只会释放一次，当大帝的大招结束之后，正常情况下会是满血，少数情况下会直接归零，俗称磕到甲沟炎了，如果是满血则需要集中火力进行输出，当大帝的血量归零时则山本结束，并会传送到奖励房中。

### 集灵宫

- ⑩：金天顺圣大帝，俗称西大帝，是西本的最终boss，西大帝拥有金木水火土五种元素机制。<br>不管是哪种元素机制，每次受到攻击后都会累计百分比掉血的致死量，当达到10次时必死，此致死量的累计包括但不限于每种元素的弹幕攻击、元素的爆炸或者灼烧等伤害，目前尽能通过轮回机制的每次死亡来清空致死量的累计数值。由于每种元素的攻击都差不多，因此仅统计容易致死的大帝机制。<br>金：有一种弹幕攻击是类似索敌一样的，需要通过左键的方式将飞行物击落，否则会急剧累计致死量。<br>木：被木元素攻击到会获得中毒效果，建议阵法师玩家在开局先给予全队浓水以清除此负面效果。<br>水：有一种机制会将玩家吸引到场地中间然后很容易被弹幕集火秒杀，务必多加留意；水还有一种攻击方式是追踪类的爆炸，此类爆炸能通过移动来躲避。<br>火：在此元素下，在场地的四周会分别生成一个火核心，默认在单人拥有20点血量，每次左键攻击都会降低1点（建议开左键连点器要不然会很累），每多一名玩家就会增加核心的血量，在满人时可达60点血量；在场地的每个格子上，会随机生成若干熔岩并造成熔岩伤害，熔岩伤害和弹幕攻击一样都会在每次受伤时累计1点的致死量，每次生成熔岩时都会提前生成红色的粒子效果，目前只能通过wasd进行躲避，建议开启F5第三人称视角以便提前躲避。<br>土：有一种机制是震地波，此震地波是全屏，如果此时躲在角落请务必活动起来，当震地波快达到面前时按一次空格进行跳跃以躲避震地伤害。<br>这五种元素中，除了火关之外，都会在机制结束后生成一只精英怪，每种元素的精英怪各有不同的技能。<br>其中金元素精英怪需要在背后攻击才能造成伤害，如果是正面攻击则会受到荆棘反伤，当把当前场地上的精英怪击杀后，大帝会从空中落下，此时拥有20秒的输出窗口期，如果配队的输出够高则能够一波击杀，如果无法一波击杀则会进入第二轮的元素机制，直到最后彻底击杀西大帝，最终便会传送至西侧的奖励房中。
