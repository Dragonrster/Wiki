# 罗盘

罗盘（卦象罗盘）是圣山副本产出的法宝，右键打开可选择不同卦象释放对应效果。

## 各罗盘效果

| 颜色 | 效果 |
|------|------|
| **红** | 群体增加 10 秒 20% 自身进攻属性的攻击力，附带移速加成。效果会被后放的罗盘覆盖，但覆盖的加成按照被覆盖前的进攻属性计算 |
| **黄** | 造成 5 次 200% 进攻属性的伤害 |
| **紫** | 召唤一个每次造成 60% 伤害的召唤物，存在 30 秒，每秒攻击一次 |
| **蓝** | 造成 2 段 450% 伤害，范围 13 格 |
| **灰** | 造成 1 段 1250% 倍率的伤害 |
| **绿** | 造成 3 段 300% 倍率的伤害 |
| **棕** | 群体增加 12 秒 150 点护甲值 |
| **白** | 持续吹飞周围怪物。摔落伤害与进攻属性及摔落格数有关，摔一次约 300%~400% 伤害，摔 3~4 次。注意头上有方块挡着或底下有水则无伤害 |

## 红色罗盘叠加说明

例如：100 进攻属性的玩家给 10 进攻属性的玩家用火 → 目标变为 30 进攻属性（100×0.2+10=30）。目标此时放罗盘 → 自身变为 16 进攻属性（30×0.2+10）。

## 获取方式

- 圣山副本开箱获取：法宝-[卦象罗盘]
