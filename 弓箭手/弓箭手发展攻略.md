# 职业的选择

弓箭手的优势是能够利用手长的方式在远距离使用高额的攻击力来攻击生物，但代价是身板比较脆，为了更好的利用高攻击所带来的优势，因此**玩弓箭手只推荐选择战神族**。

由于弓箭手的身板较脆，对于副本的单人带本能力偏弱，在后期对于材料的刷取这方面的难度偏高，如果你是一个人玩的话，不太建议选择弓箭手这个职业，目前（2026年7月30日）在盘龙阁服务器中，战士职业在刷取材料这方面的断档领先弓箭手和阵法师一大截，建议优先选择战士等待毕业之后再考虑开弓箭手小号，否则在打副本这方面的生存这块可能会有些压力。

种族特性在四圣兽试炼与圣山升级，最高六级，在游戏前期能提供极大增益。<br>升级流程：青龙试炼（1 -> 2）、朱雀试炼（2 -> 3）、白虎试炼（3 -> 4）、玄武试炼（4 -> 5）、通关一次圣山（5 -> 6）<br>

# 中期（10-40）

**在盘龙阁服务器中，弓箭手这个职业从前期到后期需要收集以下的物品（建议收藏）：[110个朱火羽、128个丝绸、292个生灵水、228个雪猿皮毛、78个千里弓弦、448个青纹灵骨、452个玄湖灵核、208个坚甲蛛壳、312个皮料、96个灵铁、256个余泪]**

当进入到中期这个阶段时，会在南方沙漠遇到马贼团长这个精英怪，团长拥有高额的攻击力和高额的血量，同时也拥有不俗的击退抗性和近战攻击力，为了更方便的击杀团长，建议选择焰铁弓。前往皇城南部的沙漠（19 49 315）击杀烈焰人体型的生物获取微火种（推荐温泉客栈门口，坐标：-365 68 339），前往马贼营地击杀马贼团长（-129 54 745）获得红宝石、蓝宝石等（也能在王员外[-283 54 395]处使用红蓝宝石互相转换）。

从四阶武器开始，由于要考虑到后续的刷级和精英怪的攻击力，建议选择蛟龙弩以提供适当的生存能力避免被秒杀。四阶武器需要28个生灵水，生灵水需要击杀活水源获得，活水源的入口坐标是[-324 146 -6]，一直往里走到底就能找到活水源唯一的刷怪点，建议从[废弃的金矿小镇]往外走更近，如果有能力建议去获取逍遥令牌解锁快速传送。

为了更好的存储箭矢，建议前往东方森林的龙须镇寻找退休的老猎户（508 51 33）使用1个银票兑换1个[老猎户的箭袋]，哪怕不是为了存储箭矢，由于箭袋也能增加箭矢强度，因此也是必须获得的法宝之一。

## DLC

**DLC副本不欢迎任何摆烂玩家，不欢迎任何没有原六毕业以及10锻以上的玩家！！！**<br>

当你原六毕业之后，就可以考虑尝试攻略本服务器的DLC副本，目前服务器有三个DLC副本，也就是[烧火境]、[峻极殿]、[集灵宫]。其中，烧火境在玩家的日常交流中主要以“烧”、“烧火”的简称为主；峻极殿的简称主要是“山本”、“中岳”为主；集灵宫的简称主要是“西本”、“西岳”为主。

在DLC副本中，请务必按照 **[烧火境] -> [峻极殿] -> [集灵宫]** 的顺序进行攻略，特别是烧火镜。比如说：如果你没有原六毕业就去打烧火镜的话、如果你没有烧火镜毕业就去打峻极殿或者集灵宫的话，你将有很大的可能性会得到到来自其他队友的亲切问候。问候的主要原因只有一个：缺少原六装备或者烧火毕业装备所带来的阵法强度从而导致浓火提供的拐力不足预期。说简单点就是没有原六毕业或者烧火毕业，贸然跨副本打就是队伍的累赘。如果是朋友互相认识的话，那可以无视这句话。

### 烧火镜

>烧火镜坐标：514 53 780 

**以下是针对弓箭手玩家的简单攻略，如果你需要了解烧火镜的详细讲解，请移步[烧火镜](/副本相关/烧火境.md)。**

- 烧火镜在组队时，一次最多拥有三名玩家，目前常见的组队配置是111，111指的是1个战士+1个弓箭手+1个阵法师。<br><br>**请勿尝试非正常的职业配置，比如021或者102等，否则你将会在试图攻略烧火镜时很容易遇到被复生炸死等许多影响游戏体验的糟糕情况！！！**<br><br>
- 烧火镜的最终boss为焰火仙，焰火仙在每次被击杀后，等待屏幕中间的进度条满后，焰火仙的全属性（攻击力、生命值等）将会得到提升，也可以站到里面的复生圈（下图的橙圈）按 **[Shift+F]** 跳过读条过程强制复活。<br><br>
- 需要注意的是，焰火仙每次复活都会强制造成**两次全屏伤害**，此伤害无法躲避，但能够通过 **浓土** 和 **土傀** 进行消除和减伤。（土傀可放置在下图的紫圈中）<br><br>
- 焰火仙对阵最大的威胁是**陨石**，当焰火仙发动此技能时，会原地起飞后对全场玩家发动追踪式360度的连续攻击，伤害极高。（建议围绕淡绿圈进行绕圈跑，跑圈路径请务必其他玩家的圈）<br><br>
- 弓箭手在烧火镜的主要攻略是：在烧火镜中间的阵法师土傀区域攻击焰火仙，如果选择的是重弓则建议去到往后撤退点的区域附近进行输出。<br><br>
- 弓箭手在攻略烧火镜的附灵携带方式有两种，一种是2集2守，另外一种的是4集。如果当前组队的阵法师的装备毕业程度比较高，比如说山本毕业或者西本毕业，那么就可以考虑4集全输出，而把生存能力交给阵法师，如果阵法师毕业程度不高则应该选择2集2守，否则在遇到陨石和复生时会很容易死。<br><br>
- 烧火镜和其他副本的死亡机制不一样，因为焰火仙的复生是无限的，所以每次死亡之后不会返回奈何桥，而是传送到奖励房并增加保底进度。<br><br>
- 烧火镜只有在攻略到第9次复生之后，才会出现烧火宝箱，烧火宝箱无法使用银钥匙或者金钥匙打开，需要使用专门的烧火钥匙，烧火钥匙可以在烧火镜门口使用 **[48个火星残砾]** 或者 **[12个焰心碎片]** 在门口的NPC兑换获得，也能使用烧火镜门口打怪掉落的材料进行兑换，请自行选择最适合自己的获取方式。 <br><br>
- 烧火镜的开箱保底是150，从复生9开始，每次复生都会增加1点的保底次数，无上限。弓箭手在烧火镜的装备有三个，分别是：[武器]掠火、[饰品]烈日箍、[法宝]赤霄印。在这三个装备出完之前，哪怕中途出了烧火材料业火宝铁也不会清空保底次数。但只要出了这三个装备的其中一个之后，保底进度就会清空。<br><br>
- 如果阵进入了速烧的烧火队伍，一般来说是在复生15或者复生17之后通过入口的退出圈进行退出。

**绿圈**：阵法师玩家遇到陨石时的绕圈范围，没有遇到陨石时可适当与弓箭手玩家一起呆在中间紫圈土傀区域。<br>

- 第六关：<br>大帝的技能机制比较多，但大多数的伤害都不高，所以无需特别在意。<br>在大帝关开始时，需要后退不要吃到大地的伤害，在大帝差不多70%血量的时候就需要尝试集火秒掉，否则会开出大招。<br>假如队伍的输出不高导致不能一轮秒掉大帝，大帝则会释放一次名为“五土归一”红色字体的大招，唯一的应对方式就是让战士使用诀窍的主动技能“玄龟护法阵”来硬吃大招，如果没有玄龟则在大招结束后全体返回奈何桥，正常情况下在有玄龟的情况下吃了大招之后全体玩家会剩50%的血，此时请务必吃回血药进行回血。<br>大帝的大招每一局只会释放一次，当大帝的大招结束之后，正常情况下会是满血，少数情况下会直接归零，俗称磕到甲沟炎了，如果是满血则需要集中火力进行输出，当大帝的血量归零时则山本结束，并会传送到奖励房中。

### 集灵宫

集灵宫，俗称西本。是盘龙阁服务器在2026年6月推出的副本，西本的机制类似于植物大战僵尸的塔防模式，需要先击杀掉兵营附近的抗性怪后才能对兵营（也就是精英怪）造成伤害，否则当抗性怪存在时，兵营则会获得80%的伤害减免。
